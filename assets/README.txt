HOW TO REPLACE A PHOTO
1. Prepare a real photo. Recommended: landscape JPG or PNG, ideally 1200px wide or more.
2. Rename it to the exact filename above. If you use JPG instead of PNG, you must also update the matching filename in index.html.
3. Copy it into this assets folder, replacing the placeholder.
4. Upload the updated assets folder to GitHub along with the website files.
